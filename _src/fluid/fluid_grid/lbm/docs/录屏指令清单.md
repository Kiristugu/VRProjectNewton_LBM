## 1. W2Full 分支 — 顶盖方腔 Demo

**1 条命令** · 顶盖驱动腔 · BGK · 流线 PNG + VTK

```powershell
git checkout W2Full

python wanphys/examples/fluid_grid_lbm_cavity.py `
  --viewer null `
  --num-frames 300 `
  --test `
  --output-dir output/video/cavity_w2full
```

**生成文件**（`output/video/cavity_w2full/`）：

| 文件 | 内容 |
|------|------|
| `cavity_bgk_speed.png` | 中截面速度流线 |
| `cavity_bgk_rho.png` | 中截面密度 |
| `cavity_bgk.vtk` | ParaView 三维场 |

> W2Full 若无 `--profile`，默认 BGK + 50³ 网格。若该分支脚本较旧、无 `--test`，改用：`--export-batch --export-vtk output/video/cavity_w2full/cavity.vtk`

## 2. Obstacle 分支 — 绕障流（共 6 条）

### 2.1 顶盖腔 + 方柱（3 条：MID / HIGH / TALL）

```powershell
git checkout <obstacle分支名>

# MID — 柱体居中
python wanphys/examples/fluid_grid_lbm_obstacle.py `
  --viewer null --num-frames 300 --test `
  --obstacle-height mid `
  --output-dir output/video/obstacle

# HIGH — 底对齐 MID，向上贴顶盖
python wanphys/examples/fluid_grid_lbm_obstacle.py `
  --viewer null --num-frames 300 --test `
  --obstacle-height high `
  --output-dir output/video/obstacle

# TALL — 自底到顶满高柱
python wanphys/examples/fluid_grid_lbm_obstacle.py `
  --viewer null --num-frames 300 --test `
  --obstacle-height tall `
  --output-dir output/video/obstacle
```

**每个高度** → `output/video/obstacle/<mid|high|tall>/`：

- `obstacle_<高度>.vtk`
- `stream_xy_z_{bottom,mid,top}.png`（侧面 ×3）
- `stream_xz_y_{bottom,mid,top}.png`（俯视 ×3）

## 3. MRT 分支 — BGK/MRT 对比（3 条）

用 **`--profile custom`** + 手动参数，保证 **300 帧**（`--profile subtle/coarse` 会覆盖帧数）。

```powershell
git checkout MRT

# ① 低 Re — BGK 与 MRT 应几乎一致
python wanphys/examples/fluid_grid_lbm_cavity.py `
  --viewer null --num-frames 300 --test --compare `
  --profile custom `
  --grid-size 64 --nu 0.16667 --u-lid 0.1 `
  --output-dir output/video/compare_subtle

# ② 高 Re 细网格 — 看差分图
python wanphys/examples/fluid_grid_lbm_cavity.py `
  --viewer null --num-frames 300 --test --compare `
  --profile custom `
  --grid-size 128 --nu 0.01024 --u-lid 0.42 `
  --output-dir output/video/compare_contrast

# ③ 粗网格高 Re — BGK 易发散，MRT 稳定（答辩重点）
python wanphys/examples/fluid_grid_lbm_cavity.py `
  --viewer null --num-frames 300 --test --compare `
  --profile custom `
  --grid-size 32 --nu 0.00256 --u-lid 0.2 `
  --output-dir output/video/compare_coarse
```

**每条 compare** 依次跑 BGK → MRT，输出目录示例（`compare_coarse/`）：

| 文件 | 说明 |
|------|------|
| `cavity_bgk_speed.png` / `cavity_bgk_rho.png` | BGK 流线（coarse 下 BGK 可能 NaN，无图） |
| `cavity_mrt_speed.png` / `cavity_mrt_rho.png` | MRT 流线 |
| `cavity_bgk.vtk` / `cavity_mrt.vtk` | VTK |
| `cavity_diff_rho.png` / `cavity_diff_speed.png` | 差分图（BGK 正常时才有） |

> **coarse** 录屏时重点拍终端：BGK 段 `max|u|=nan`，MRT 段正常结束。

## 4. 录屏顺序建议（约 10 段）

| 顺序 | 分支 | 内容 | 时长粗估 |
|------|------|------|----------|
| 1 | W2Full | 顶盖方腔 | ~30 s |
| 2–4 | Obstacle | 腔体 MID / HIGH / TALL | 各 ~20 s |
| 5–7 | Obstacle | 通道 cylinder / box / both | 各 ~1–3 min |
| 8 | MRT | compare subtle | ~1 min |
| 9 | MRT | compare contrast | ~5 min（128³ 较慢） |
| 10 | MRT | compare coarse | ~30 s |

**128³ contrast 最慢**；若录屏超时，可把第 9 条改为 `--grid-size 64 --nu 0.025 --u-lid 0.16`（stress 档，约 1 分钟）。

## 5. 常见问题

**Q：终端长时间无输出？**  
MRT / 128³ 正常偏慢，看 `[bgk]` / `[mrt] frame=…` 是否在涨。

**Q：想改用 preset 名？**  
`--profile subtle --compare` 可以，但帧数由 preset 决定（非 300），不适合本清单的统一帧数。

**Q：ParaView 打开哪个 VTK？**  
绕障用带 `solid` 的；腔体对比用 `cavity_mrt.vtk` 或 `cavity_bgk.vtk`。
