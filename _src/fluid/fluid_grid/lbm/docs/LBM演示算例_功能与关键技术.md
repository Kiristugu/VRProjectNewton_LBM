# LBM 演示算例：功能点与关键技术（答辩提纲）

> 详细参数与命令见 [`obstacle_flow_cases.md`](obstacle_flow_cases.md)、[`bgk_mrt_compare_summary.md`](bgk_mrt_compare_summary.md)

---

## 1. 做了什么

在 **Warp GPU** 上实现 **D3Q19 LBM**，完成三类演示：

| 演示 | 脚本 | 一句话 |
|------|------|--------|
| **顶盖方腔** | `fluid_grid_lbm_cavity.py` | 经典 lid-driven cavity，主涡 + 批量出图 |
| **腔体绕障** | `fluid_grid_lbm_obstacle.py` | 顶盖腔中央方柱，三种柱高 |
| **通道绕障** | `fluid_grid_lbm_channel_obstacle.py` | 来流绕圆柱/方柱，俯视图尾迹 |
| **BGK/MRT 对比** | cavity + `--profile --compare` | 同算例下对比两种碰撞格式 |

---

## 2. 关键技术（答辩口径）

- **求解器**：碰撞 → 迁移（Pull）→ 边界 → 更新 ρ、u；GPU 并行
- **边界**：速度型（顶盖/壁面）、压力型（通道出口）；固体格点 bounce-back
- **障碍**：格点标记 `solid`，流场绕开
- **后处理**：matplotlib 流线 PNG、VTK 供 ParaView 查看

---

## 3. 各演示功能点

### 3.1 顶盖方腔

- 五壁固定 + 顶盖匀速驱动，形成腔体内主涡
- 支持 **BGK / MRT**（及 TRT）切换
- 输出：中截面流线 PNG、VTK

### 3.2 腔体绕障（方柱）

- 在顶盖腔中央放置 **方盒障碍**
- 三种高度：**MID / HIGH / TALL**（由矮到顶盖贯通）
- 输出：侧面 + 俯视多张流线 PNG、带 solid 的 VTK

### 3.3 通道绕障

- 水平通道来流，**圆柱或方柱**（沿高度方向贯穿）
- 输出：俯视图尾迹、速度剖面曲线、VTK

### 3.4 BGK 与 MRT 对比

| 预设 | 要点 | 答辩怎么说 |
|------|------|------------|
| **subtle** | 低 Re | 两者结果一致，说明实现正确 |
| **coarse** | 粗网格 + 高 Re | **BGK 发散，MRT 仍稳定** → MRT 的价值 |
| **contrast** | 细网格 + 更高 Re | 差分图可见细微差别 |

> 低 Re 时两者很像；**MRT 主要优势在难算的高 Re / 粗网格稳定性**，不是平时流场差很多。

## 4. 不足与局限（主动说明，宜简不宜细）

**已观察到的：**

- 方腔**底角小涡不明显** — 网格与 Re 有限，边界为简化处理，且为 3D 方盒非理想 2D 算例
- 通道**圆柱呈阶梯状** — 障碍由格点离散，非光滑曲边界

**其它：**

- 边界条件为简化平衡态格式，角点未专门处理
- 圆柱/方柱无曲边界拟合；通道入口为均匀来流
- MRT 实现为简化版，与 BGK 在稳定工况下结果接近；MRT 计算较慢
- 固定步数推进，未做与文献基准的定量对比

**后续可改进：** 加密网格 / 改进边界与障碍几何 / 完善 MRT 参数

## 5. 答辩演示建议

1. **主涡**：顶盖腔流线 PNG
